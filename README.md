# Lagos Life beginner checklist (unofficial fan guide)

This repository is a short unofficial fan guide for the life-simulation game Lagos Life. It is **not affiliated with Vatar or the developer**. All game names and trademarks belong to their owners.

The official game is the web version at lagoslife.app.

Full English guide: https://lagoslife.games

## Beginner checklist

1. Play the official web game at lagoslife.app, then use this fan guide to plan jobs and rent.
2. Learn the basic loop: work a job, collect salary, pay rent, then spend leftover naira on upgrades.
3. Read the how-to-play walkthrough before you take a high-rent apartment.
4. Compare job salaries with rent using the free calculators on the tools page.
5. Revisit the jobs page when you change neighborhoods.
